# فكّ التخبيص

أداة ويب صغيرة تستعيد النص الذي كتبته بتخطيط لوحة مفاتيح خاطئ بدل أن تعيد كتابته. تحوّل الحروف بحسب **مواقع المفاتيح** بين Arabic (101) وEnglish (US) QWERTY، وليست مترجمًا ولا مصححًا لغويًا.

فيها أربعة أوضاع (إصلاح العربية المكتوبة بتخطيط إنجليزي، وإصلاح الإنجليزية المكتوبة بتخطيط عربي، والاتجاهان العكسيان)، وتحويل فوري أثناء الكتابة، ونسخ ومسح بضغطة، وتنبيه بالأحرف التي لا يمكن تحويلها بدل حذفها بصمت. تعمل كلها داخل المتصفح بـ HTML وCSS وJavaScript دون خادم ولا اتصال بالإنترنت، بتصميم داكن يدعم RTL وLTR.

> ملاحظة: «لا» قد تقابل المفتاح B أو المفتاحين G+H، فتُفسَّر كمفتاح B.


هذا المشروع مفتوح المصدر برخصة MIT.

ملاحظة: ملف الأداة الرئيسي محفوظ باسم "فكّ التخبيص.html" في جذر المستودع. لإظهار المشروع على GitHub Pages تم إضافة ملف تحويلي `index.html` لإعادة التوجيه.
